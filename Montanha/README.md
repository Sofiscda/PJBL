Ilha dos Desafios - Montanha

Projeto desenvolvido em Python para a disciplina de Raciocínio Algorítmico.

Descrição

O jogo consiste em subir uma montanha enfrentando diferentes obstáculos. Durante o percurso, o jogador precisa escolher caminhos, responder perguntas de conhecimentos gerais e administrar sua energia para chegar ao topo.

Funcionalidades

- Escolha entre diferentes caminhos e obstáculos.
- Perguntas fáceis e difíceis.
- Sistema de pontuação.
- Sistema de energia com perdas aleatórias.
- Finais diferentes de acordo com a energia restante.
- Salvamento dos resultados dos jogadores.
- Ranking geral.
- Gráfico para comparar o desempenho dos jogadores.

Requisitos

- Python 3 instalado.
- Biblioteca Matplotlib.

Bibliotecas utilizadas

- random: geração aleatória das perdas de energia.
- json: armazenamento dos resultados dos jogadores.
- matplotlib: criação de gráficos.

Instalação

Instalar a biblioteca Matplotlib pelo terminal:

    python -m pip install matplotlib
